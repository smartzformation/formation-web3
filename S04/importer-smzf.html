Afficher mes jetons SMZF dans MetaMask

Un guide pas à pas pour ajouter le jeton de la formation sur le réseau de test Sepolia.

SMZForm · SMZFSepolia18 décimales
Importer ≠ recevoir. L’importation affiche un jeton dans votre portefeuille. Elle ne crée aucun jeton et ne vous en attribue pas. Votre solde dépend des transferts reçus du formateur. L’importation est gratuite et ne nécessite aucune transaction blockchain.

1. Préparer l’adresse du jeton

L’adresse du contrat SMZForm est déjà renseignée ci-dessous. Cliquez sur Copier l’adresse pour l’utiliser dans MetaMask. Ce n’est pas votre adresse personnelle de portefeuille.

En attente de l’adresse du contrat.

Le bouton d’ajout ouvre une demande dans le portefeuille compatible du navigateur. Vérifiez que c’est bien MetaMask. Vous pouvez aussi suivre la méthode manuelle ci-dessous. Une adresse au bon format n’est pas une preuve d’authenticité : comparez-la avec celle du formateur.

2. Suivre la procédure manuelle

1

Ouvrir le bon compte

Ouvrez MetaMask et sélectionnez le compte dont vous avez communiqué l’adresse au formateur.

2

Sélectionner Sepolia

Dans le sélecteur de réseaux, choisissez Sepolia. S’il est absent, activez l’affichage des réseaux de test dans les paramètres ou dans le sélecteur, selon votre version.

3

Ajouter un jeton personnalisé

Dans Jetons / Tokens, ouvrez le menu ⋮ → Gérer les jetons, ou Importer des jetons / + selon votre version. Choisissez l’ajout par adresse ou l’onglet Jeton personnalisé.

4

Renseigner les informations

Collez l’adresse du contrat. Si les champs ne se remplissent pas automatiquement, indiquez SMZF pour le symbole et 18 pour les décimales. Si MetaMask affiche d’autres données, faites vérifier l’adresse avant de continuer.

5

Confirmer et lire le solde

Cliquez sur Suivant, puis Importer / Ajouter. Revenez à la liste des jetons : SMZF doit apparaître. Vous ne recevez pas le million émis : le formateur vous transfère la quantité prévue pour l’exercice.

3. Vérifier que tout est prêt

0 / 4 vérifications effectuées

Un problème ?

Je vois SMZF, mais mon solde est à zéro

L’affichage est prêt. Vérifiez que le formateur a envoyé les jetons à votre compte sur Sepolia et que la transaction est confirmée. Importer seul ne donne aucun jeton.

Je ne trouve pas SMZF dans la recherche

Utilisez l’ajout par adresse : ce jeton pédagogique n’est pas nécessairement référencé dans la recherche MetaMask.

Le bouton d’ajout ne fonctionne pas

Utilisez un navigateur avec MetaMask installé, ou le navigateur intégré à MetaMask sur mobile. Sinon, suivez la procédure manuelle. Si Sepolia n’est pas proposé, sélectionnez-le directement dans MetaMask puis recommencez.

Le prix en euros n’apparaît pas

C’est attendu pour cet exercice : les SMZF sur Sepolia sont des jetons de test, sans valeur monétaire attribuée dans la formation.

Faut-il des SepoliaETH ?

Pas pour importer ou recevoir les SMZF. Pour en envoyer à un autre apprenant, il faut des SepoliaETH sur votre compte afin de payer les frais de transaction.

Bon réflexe : aucune phrase de récupération ni clé privée n’est nécessaire pour importer un jeton. Ne les saisissez jamais sur cette page.
